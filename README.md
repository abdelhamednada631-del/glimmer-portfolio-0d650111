# توثيق مشروع بوت تلجرام لإدارة GitHub وموقعه التعريفي

## 1. مقدمة عن المشروع

هذا المشروع عبارة عن حل متكامل لإدارة مستودعات GitHub مباشرةً من خلال بوت تلجرام، مدعومًا بموقع تعريفي احترافي يسلط الضوء على ميزاته ويسهل على المستخدمين البدء. يهدف المشروع إلى تبسيط تفاعلات المطورين مع GitHub، مما يتيح لهم تنفيذ مهام أساسية مثل عرض المستودعات، رفع الملفات، تحميلها، وتغيير خصوصيتها، كل ذلك من بيئة تلجرام المألوفة. تم تصميم البوت كخدمة (SaaS) لدعم تعدد المستخدمين مع ضمان الأمان وقابلية التوسع.

## 2. بوت تلجرام لإدارة GitHub (مستودع GIT5)

### 2.1. نظرة عامة والميزات الرئيسية

بوت تلجرام هذا هو أداة قوية مصممة لتمكين المستخدمين من إدارة مستودعات GitHub الخاصة بهم بكفاءة. يقدم البوت مجموعة واسعة من الميزات التي تلبي احتياجات المطورين، مما يجعله حلاً شاملاً لإدارة GitHub عبر تلجرام [1].

**الميزات الأساسية:**

*   **ربط آمن لحساب GitHub**: يسمح للمستخدمين بربط حساباتهم على GitHub باستخدام Personal Access Token (PAT) الذي يتم تشفيره وتخزينه بشكل آمن [1] [2].
*   **إدارة المستودعات**: يوفر وظائف لعرض قائمة المستودعات الخاصة بالمستخدم، وحذف المستودعات، وتحميلها كملفات ZIP [1] [3].
*   **رفع ملفات ZIP كمستودعات**: يمكن للمستخدمين رفع ملفات ZIP، ويقوم البوت تلقائيًا بإنشاء مستودع جديد على GitHub ورفع محتويات الملف المضغوط إليه، مع دعم لأسماء المستودعات الافتراضية أو المخصصة [1] [3].
*   **تغيير خصوصية المستودعات**: يتيح للمستخدمين تبديل خصوصية مستودعاتهم بين عام (Public) وخاص (Private) بسهولة [3].
*   **جلب المستودعات العامة**: يمكن للمستخدمين تحميل ملفات أي مستودع عام على GitHub عن طريق توفير الرابط الخاص به [3].
*   **نظام SaaS متعدد المستخدمين**: يدعم البوت تعدد المستخدمين، حيث يتم إدارة جلسات منفصلة وتشفير PAT لكل مستخدم لضمان الخصوصية والأمان [1] [2].
*   **جاهزية النشر**: مهيأ بالكامل للنشر على منصات مثل Railway باستخدام Docker، مما يضمن سهولة الإعداد والتشغيل [1] [2].

### 2.2. التقنيات المستخدمة

تم بناء البوت باستخدام مجموعة من التقنيات الحديثة لضمان الأداء والأمان وقابلية الصيانة [1]:

*   **اللغة**: Python 3.11
*   **مكتبات البايثون**: `python-telegram-bot` للتفاعل مع تلجرام، `PyGithub` للتفاعل مع GitHub API، و `cryptography` للتشفير.
*   **قاعدة البيانات**: SQLite لتخزين بيانات المستخدمين و PATs المشفرة، مع دعم Volumes للنشر المستمر [1] [2].
*   **النشر**: Docker و Railway.

### 2.3. الهيكل المعماري (Architecture)

يعتمد البوت على هيكل معماري معياري يضمن فصل الاهتمامات ومرونة التطوير [2]:

*   **واجهة تلجرام (Telegram Interface)**: مسؤولة عن استقبال الأوامر والرسائل من المستخدمين وإرسال الردود إليهم باستخدام `python-telegram-bot`.
*   **معالج منطق البوت (Bot Logic Handler)**: يفسر أوامر المستخدم، ينسق العمليات بين المكونات الأخرى، ويدير حالات المحادثة.
*   **خدمة GitHub (GitHub Service)**: طبقة تجريد للتفاعل مع GitHub API، مسؤولة عن جميع عمليات GitHub مثل إنشاء/حذف/عرض المستودعات ورفع/تحميل الملفات [2].
*   **خدمة إدارة المستخدمين (User Management Service)**: تدير بيانات المستخدمين وتخزن GitHub PATs بشكل آمن في قاعدة البيانات [2].
*   **وحدة معالجة الملفات (File Processing Module)**: تتعامل مع ملفات ZIP، تفك ضغطها، تعالجها، وتجهزها للرفع إلى GitHub [2].

### 2.4. اعتبارات الأمان

يولي المشروع اهتمامًا كبيرًا للأمان، خاصة فيما يتعلق ببيانات المستخدمين الحساسة:

*   **تشفير Personal Access Tokens (PATs)**: يتم تشفير جميع PATs الخاصة بالمستخدمين باستخدام مكتبة `cryptography` قبل تخزينها في قاعدة البيانات، مما يضمن حمايتها من الوصول غير المصرح به [1] [2].
*   **التعامل الآمن مع الملفات**: يتم التعامل مع الملفات المؤقتة التي يتم تحميلها أو فك ضغطها بشكل آمن، ويتم حذفها تلقائيًا بعد الانتهاء من معالجتها لتوفير المساحة وضمان الخصوصية [1] [2].
*   **التحقق من صلاحية التوكن**: يتم التحقق من صلاحية PAT عند كل استخدام لضمان استمرارية الخدمة وأمانها [3].

## 3. الموقع التعريفي (مستودع github-bot-website)

### 3.1. نظرة عامة والغرض

يعمل الموقع التعريفي كواجهة تسويقية وجذابة لبوت تلجرام لإدارة GitHub. يهدف الموقع إلى تقديم المشروع للجمهور، شرح ميزاته، توضيح كيفية عمله، والإجابة على الأسئلة الشائعة، مما يشجع المستخدمين على البدء في استخدام البوت [4].

### 3.2. التقنيات المستخدمة

تم بناء الموقع باستخدام أحدث تقنيات تطوير الويب لضمان تجربة مستخدم سلسة وتصميم عصري [4]:

*   **بيئة التطوير**: Node.js 20، Vite v7.2.4.
*   **إطار العمل**: React مع TypeScript.
*   **التصميم**: Tailwind CSS v3.4.19 مع مكونات `shadcn/ui` لتوفير واجهة مستخدم جميلة ومتجاوبة.
*   **الرسوم المتحركة**: `framer-motion` لإضافة تأثيرات بصرية جذابة وتفاعلية.

### 3.3. الأقسام الرئيسية للموقع

يتكون الموقع من عدة أقسام مصممة لتوجيه الزائر خلال رحلة اكتشاف البوت [4]:

*   **Hero Section**: القسم الرئيسي الذي يقدم البوت برسالة واضحة وجذابة، مع إحصائيات وهمية (مثل عدد المستخدمين والمستودعات المدارة) وعرض تفاعلي لأوامر البوت في واجهة تشبه الطرفية [4].
*   **Features Section**: يسلط الضوء على الميزات الرئيسية للبوت بطريقة سهلة الفهم.
*   **How It Works Section**: يشرح خطوات استخدام البوت بدءًا من الربط بحساب GitHub وحتى إدارة المستودعات، غالبًا ما يتضمن رسومًا توضيحية أو محاكاة لتجربة المستخدم [4].
*   **Commands Section**: يعرض قائمة مفصلة بجميع الأوامر المدعومة من قبل البوت، مع وصف لكل أمر وأمثلة على استخدامه [4].
*   **FAQ Section**: يجيب على الأسئلة الشائعة حول البوت، مثل أمان التوكن، متطلبات الصلاحيات، وحدود حجم الملفات [4].
*   **Developer Section**: قسم تعريفي بالمطور، يعرض معلومات عن خبرته ومهاراته، مع روابط لحساباته الاجتماعية [4].
*   **Footer**: يحتوي على روابط التنقل، روابط وسائل التواصل الاجتماعي، ومعلومات حقوق النشر.

## 4. القيمة المضافة والتأثير

يقدم هذا المشروع قيمة كبيرة للمطورين من خلال توفير أداة فعالة ومريحة لإدارة GitHub. من خلال دمج وظائف GitHub القوية في بيئة تلجرام، يقلل البوت من الحاجة إلى التبديل بين التطبيقات ويسرع سير العمل. يضمن التصميم المعماري القوي والأمان المدمج أن يكون المشروع موثوقًا وقابلًا للتوسع، بينما يوفر الموقع التعريفي تجربة مستخدم ممتازة ويزيد من جاذبية المشروع.

## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
